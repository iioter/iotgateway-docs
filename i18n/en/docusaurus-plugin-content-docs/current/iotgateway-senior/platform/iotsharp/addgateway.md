# Gateway Connection

This tutorial uses **IoTSharp gateway** for device data ingestion.

:::danger Important
You must complete the IoTGateway tutorial first.
:::

## Add Gateway

Note the **Device Type** and **Authentication Method** settings.

## Copy Gateway Token

Copy the gateway access token for IoTGateway configuration.

## Modify Gateway Configuration

Configure the IoTSharp platform connection in IoTGateway with the server URL and gateway token.

## Verify Devices Online

In the IoTSharp device list, you can see the gateway and sub-devices all online.
